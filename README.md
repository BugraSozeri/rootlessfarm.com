# Rootless Farm

**Website: [rootlessfarm.com](https://rootlessfarm.com/)**

An instrumented field manual for hydroponics: 53 plant profiles with pH, EC and DLI targets, 18 free calculators, and AI plant diagnosis. Every claim sourced.
